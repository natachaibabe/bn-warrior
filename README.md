# BN Warrior V11

แอปออกกำลังกาย 84 วันแบบ PWA สำหรับใช้งานส่วนตัว

## ติดตั้งผ่าน GitHub Pages

1. สร้าง Repository ใหม่บน GitHub ชื่อ `bn-warrior`
2. แตกไฟล์ ZIP นี้
3. อัปโหลด **ไฟล์และโฟลเดอร์ที่อยู่ด้านในทั้งหมด** ไปที่หน้าแรกของ Repository  
   ต้องเห็น `index.html` อยู่ที่ระดับบนสุด ไม่ควรมีโฟลเดอร์ซ้อนอีกชั้น
4. ไปที่ **Settings → Pages**
5. ในหัวข้อ **Build and deployment**
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
6. กด **Save** แล้วรอประมาณ 1–3 นาที
7. เปิด URL ที่ GitHub แสดงในหน้า Pages

URL โดยทั่วไปจะมีรูปแบบ:

`https://ชื่อผู้ใช้.github.io/bn-warrior/`

## ติดตั้งบนมือถือ

### Android / Chrome
1. เปิด URL ของ GitHub Pages
2. กดปุ่ม **ติดตั้งแอป** ภายใน BN Warrior  
   หรือเปิดเมนู Chrome แล้วเลือก **ติดตั้งแอป / Add to Home screen**

### iPhone / Safari
1. เปิด URL ด้วย Safari
2. กดปุ่ม Share
3. เลือก **Add to Home Screen / เพิ่มไปยังหน้าจอโฮม**

## การบันทึกข้อมูล

- บันทึกอัตโนมัติทุกครั้งที่กรอกหรือติ๊กข้อมูล
- เก็บซ้ำใน `localStorage` และ `IndexedDB`
- ทำงานออฟไลน์ได้หลังเปิดเว็บสำเร็จครั้งแรก
- ข้อมูลอยู่ในอุปกรณ์และเบราว์เซอร์ที่ติดตั้ง
- ควรกด **สำรองข้อมูล** อย่างน้อยสัปดาห์ละครั้ง
- เมื่อต้องย้ายเครื่อง ให้ Export Backup จากเครื่องเดิม แล้ว Import ในเครื่องใหม่

## การอัปเดตเวอร์ชันในอนาคต

อัปโหลดไฟล์เวอร์ชันใหม่ทับไฟล์เดิมใน Repository แล้วรอสักครู่ จากนั้นเปิดแอปและรีเฟรช ข้อมูลส่วนตัวจะยังอยู่ในเบราว์เซอร์เดิม
